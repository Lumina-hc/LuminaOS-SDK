LuminaOS SDK

Everything you need to build applications for LuminaOS. Write in C, compile to LSP, deploy to the desktop.

Features

Graphics API

Pixel drawing, rectangles, text rendering, screen flush.

Input Handling

Keyboard and mouse input with blocking and non-blocking modes.

File System

Read, write, and list files on the FAT16 data disk.

Window System

Window info, close detection, and cursor management.

LSP Format

Compact 16-byte header binary format loaded by the kernel.

Example Apps

Notepad, Files, About, System — ready to study and extend.

Quick Start

  1. Install dependencies: NASM i686-elf-gcc
  2. Clone the repository: git clone https://github.com/Lumina-hc/LuminaOS-SDK.git
  3. Build an example: .\build_app.ps1 -Source examples\notepad.c -OutputDir out
  4. Deploy: copy the .lsp file to the LuminaOS data disk (hdd.img).
  5. Boot LuminaOS and click the icon to run.
